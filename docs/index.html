校验下载是否完整

断点续传、镜像改写都可能让包缺字节。装之前核一次，十秒的事。

# Windows（cmd 或 PowerShell）
certutil -hashfile app-alpine.apk SHA256

# macOS
shasum -a 256 app-alpine.apk

# Linux / 手机上的 termux
sha256sum app-alpine.apk

注意：哈希必须与上面那串完全一致。不一致就换镜像重下，不要装。

装之前知道这几件事

架构arm64-v8a
最低系统Android 8.0
targetSdk28（proot 必需）
覆盖安装同签名即可

签名：所有版本都用 android/keystore/sparkshell.jks（alias sparkshell）自签，所以 1.x → 3.9.1 可以直接覆盖升级，不用卸载。若系统提示「签名不一致」，说明你装过别的包名同款的包，先卸载旧的。

应用内更新：走的是 latest.json + 6 路 Range 下载 + sha256 校验。隧道域名一变，应用内更新就失效 —— 这时候用本页链接手动装一次即可，数据不会丢（会话、记忆、容器都在私有目录里）。
